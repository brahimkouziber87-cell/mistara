# مِسطرة (Mistara) — منظومة إعداد تقارير الفروض المحروسة لمادة الرياضيات

تطبيق ويب تربوي متكامل (PWA) مخصص لأساتذة مادة **الرياضيات بالسلك الثانوي التأهيلي في المغرب**، لإعداد تقارير الفروض المحروسة، وملفات التفتيش الموحّدة، وبطاقات الدعم الفردية انطلاقاً من ملفات النقط المصدّرة من منظومة **مسار (Massar)**، وفق مذكرة التقويم التربوي والتوجيهات التربوية الرسمية.

## أبرز المزايا
- **استيراد ذكي لملفات مسار (`.xlsx`, `.xls`, `.csv`):** استخراج تلقائي للمعطيات الإدارية، لائحة التلاميذ، النقط، وحالات الغياب، مع إمكانية التعديل المباشر والفرز حسب الاستحقاق أو فئات التحكم.
- **مُضبِط ومدقّق مذكرة التقويم للرياضيات:** تدقيق آلي للمدة القانونية، أوزان الفروض، جدول التخصيص، وآجال التصحيح حسب كل شعبة ومسلك بالتأهيلي (`TCSF`, `1BAC SM/SE/ECO/LSH`, `2BAC SM/PC/SVT/ECO/LSH`).
- **بنك كفايات وأطر الرياضيات المرجعية:** قوائم معيارية للمضامين، التعثرات الديداكتيكية الشائعة، وإجراءات المعالجة القابلة للإدراج بنقرة واحدة.
- **شبكة تحليل التمارين والكفايات (Item Analysis Matrix):** رصد نقط كل تمرين وحساب نسب التحكم وتصدير/استيراد قوالب Excel.
- **توليد تشخيص تربوي ذكي (AI + محلي بدون إنترنت):** دعم التوليد عبر Gemini API مع محرك ذكي محلي تلقائي يشتغل حتى دون اتصال أو مفتاح API.
- **تخصيص توقيع الأستاذ:** إمكانية كتابة التوقيع يدوياً أو رفع صورة توقيع شفاف (PNG) وإدراجها تلقائياً في التقارير وبطاقات الدعم.
- **تقارير A4 جاهزة للطباعة والتصدير:** تصدير بصيغة **PDF**، و**Word (`.doc`)**، و**Excel (`.xlsx`)**، مع دعم المسالك الدولية (**العربية / Français BIOF / English**)، وبطاقات الدعم الفردية، ولوحة التتبع التطوري (`F1 ← F4`) ومجالس الأقسام.

## التشغيل المحلي (Run Locally)

**المتطلبات:** Node.js 20+

```bash
# 1. تثبيت الحزم
npm install

# 2. (اختياري) ضبط مفتاح Gemini API في ملف .env
# GEMINI_API_KEY=your_api_key_here

# 3. تشغيل التطبيق في وضع التطوير
npm run dev
```

## التحقق والبناء (Lint & Production Build)

```bash
npm run lint
npm run build
```
